# Renaissance Symposium + CIHOF — Floripa

Landing page desenvolvida para o **Renaissance Symposium + CIHOF**, evento voltado à estética, ciência, saúde integrativa, regeneração, wellness, inovação e cirurgia estética da face.

## ✨ Sobre o projeto

O projeto foi desenvolvido com o objetivo de criar uma experiência digital sofisticada, moderna e responsiva para apresentar o evento, seus palestrantes, programação, local, experiências e informações para inscrição.

A identidade visual combina tons de verde profundo, tons neutros e detalhes dourados, criando uma estética premium e contemporânea.

## 🎯 Objetivos

- Apresentar o Renaissance Symposium + CIHOF
- Destacar os palestrantes e conteúdos do evento
- Apresentar a programação dos dois dias
- Divulgar o local do evento
- Facilitar o acesso às inscrições
- Criar uma experiência visual moderna e responsiva
- Adaptar a experiência para computadores, tablets e celulares

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git
- GitHub

## 📱 Responsividade

A landing page foi desenvolvida para funcionar em diferentes tamanhos de tela:
